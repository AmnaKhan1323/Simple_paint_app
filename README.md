# 🎨 Simple Paint App

A lightweight, browser-based paint and drawing application built with plain HTML, CSS, and JavaScript using the HTML5 Canvas API.

## ✨ Features

- Freehand drawing on an HTML5 canvas
- Simple, dependency-free single-page implementation
- Runs entirely in the browser with no build step

## 🧰 Tech Stack

HTML5 Canvas, CSS, JavaScript

## 🚀 Getting Started

```bash
git clone https://github.com/AmnaKhan1323/Simple_paint_app.git
cd Simple_paint_app
# Open index.html directly in your browser
```
